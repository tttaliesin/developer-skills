# Local implementation ownership

This package owns decomposition, exclusive file ownership, worktree isolation, integration and verification of an already authorized local implementation.
Workspace-wide category, authorization and GitHub lifecycle policies remain owned by workspace-rules.
Reuse the approved target, action, environment and validity conditions through skill routing.
A phase transition does not expire approval; per-execution gates, credential boundaries and explicit expiry still apply to the affected action.
Preserve existing tracked, untracked and ignored files.

Load the installed `github-operations` skill for Issue classification and remote effects.
If it is unavailable, continue independently authorized local work and report the missing remote-operation policy before that operation.
This package never creates permission for push, merge, release, dispatch, cleanup or installation.
Use repository-provided validation; successful worker checks do not replace integrated verification.

The maintained workflow in `SKILL.md` includes the worker contract, safe worktree creation, dispatch, integration, validation and handoff.
Changes to workspace-wide policy should be proposed to its owner; revise this compact boundary only to reflect an accepted contract change.
