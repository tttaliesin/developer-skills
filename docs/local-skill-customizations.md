# 외부 스킬 개인 수정 메모

이 저장소의 여섯 스킬과 별개로, 외부에서 관리하는 스킬에 적용했던 개인 수정의 의도를 정리한다.
아래 내용은 2026-09-05~06의 수정·검토 기록이며 현재 설치본에 반영되어 있다는 보장은 아니다.
현재 지침과 비교할 때 참고하며 자동 적용하지 않는다.

| 스킬 | 수정 의도 |
| --- | --- |
| doc-coauthoring | 사용자가 대화식 공동 작성을 요청한 경우에만 단계별 확인 사용; 일반 작성 요청은 완성 초안까지 진행 |
| find-skills | 적합한 스킬이 없어도 이미 요청한 작업은 가능한 도구로 계속 수행; 검색만 요청했다면 검색 결과만 보고 |
| OpenAI Docs | 사용자 지침 검토는 로컬 파일부터 확인; 최신 제품 동작에 의존하는 주장에 공식 문서 확인 적용 |
| PDF | 최종 렌더링·이미지 검사는 유지하되, 내용 누락·겹침·읽을 수 없는 글자·잘못된 값 등을 해결한 뒤 미적 선호만으로 반복 수정하지 않기 |

이미 받은 승인은 같은 대상과 작업 범위에서 재사용한다.
새로운 검색 범위나 명시적 승인 조건까지 생략하는 의미는 아니다.
PDF 렌더링이나 검사가 불가능하면 검증 완료로 전달하지 않고 현재 산출물과 확인하지 못한 범위를 알린다.
